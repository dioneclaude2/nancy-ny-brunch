# Nancy — NY Brunch projector

Fullscreen projector loop for the Nancy NY Brunch tennis activation.
**Smash the Quiet. Ace the Point.**

Open `index.html`, press `F` for fullscreen, and leave it running — nine
concepts auto-advance every 14 seconds and the loop never ends. Works on a
phone as well as a projector.

| Key | Action |
|---|---|
| `1`–`9` | Jump to a concept |
| `T` | Back to the opener |
| `←` / `→` | Previous / next line |
| `Space` | Pause / resume |
| `F` | Fullscreen |

No build step, no dependencies, no network required — fonts and artwork are in
the repo.

This is the London pop-up deck's design with the words and graphics changed;
see `BRIEF.md` for what was swapped and the two deliberate departures.
